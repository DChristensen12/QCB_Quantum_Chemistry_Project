# Predicting IR Spectra Project

Quantum selected configuration interaction (QSCI, also called SQD) has been tested almost entirely on electronic structure. Our group will be applying it to the vibrational Hamiltonian instead.

The question: does a configuration space sampled from a quantum circuit reproduce a molecule's infrared spectrum as well as one chosen by classical perturbative screening, at the same subspace size?
